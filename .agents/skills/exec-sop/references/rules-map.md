## 安全底线（写相关代码前扫一眼；完整表见项目治理 §7）

- **S-1** 硬保护规则在判定流水线最前短路，不可配置覆盖。
- **U-2** 程序自身仅在 `%LOCALAPPDATA%\DiskAudit\` 写入。
- **U-4** 系统交互白名单仅 A1~A3；`UninstallString` 只采集、永不调用。
- **DPAPI** `Roaming\Microsoft\Protect`、`Crypto` 永久"受保护"。
- **提权** 仅用户点击触发；提权后只读、不联网、不执行外部程序。
- **隐私** 不收集、不上传、默认不联网（联网代码仅"检查更新"一处）。

## 环境速查（权威记录见环境基线）

- `python` / `py` 是 Windows Store 存根（执行挂起）→ 一律用完整解释器路径（W0 POC 的 CPython 3.13.5，含 Tcl/Tk 8.6）。
- PowerShell 7：`C:\Program Files\PowerShell\7\pwsh.exe`，加 `-NoProfile -NonInteractive`。
- Appx 采集子进程：绝对路径 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`。
- AI 会话 Git Bash 沙箱：原生 Windows exe 挂起，MSYS 工具（ls/cp/mv/find/df/md5sum）正常；git/python 验证交负责人终端，AI 产出命令清单。
- VM 磁盘定址 `H:\Virtual Machine\`（DR-003）；`*.vhdx` 永不进 git。
