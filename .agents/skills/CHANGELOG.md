# CHANGELOG

本文件是 vibe-skills 包的版本变更单一事实源：版本号、生效日期、变更依据、影响文件、迁移说明与弃用规则在此登记。契约字典正文首部的「契约字典版本」锚点取自本文件最新条目；各安装副本随包同步，不得独立改版。本文件随发布副本复制到包根，不复制到各技能目录内；三处安装根同样保留一份。包根指维护源包根、发布副本根或安装根，即七个技能目录的共同父目录。

- 变更依据/批准人：项目负责人在本会话明确指令——独测通过后由独测提PR附报告，失败直接回执行侧；CI后PM验收，通过后直接合入，无需逐项授权，验收形式由PM裁决。PM记录本项目采用和持续授权；其他项目仍需自己的采纳与授权。

- 影响：七技能、契约、模板、README、离线检查器与回归、效果评测版本备注；新发布r6及三处安装同步。报告附PR正文/评论，绑定完整SHA/version/hash，原件独立保留，不提交进被测树。
