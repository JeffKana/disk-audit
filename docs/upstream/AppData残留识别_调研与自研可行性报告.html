结论速览（TL;DR）
  1. 市面已有成熟软件。"卸载残留检测"是专业卸载器的标配功能（Revo、HiBit、Geek、IObit 均内置卸载后残留扫描）；事后全盘"孤儿识别"（你的场景）以开源的 Bulk Crap Uninstaller 最完善，CleanMyPC 曾以此为核心卖点但已于 2025 年 4 月停运。
  2. 技术方案成熟。三条路线均经商业验证：安装监控快照（最准、只管未来）、卸载后残留扫描（主流）、事后交叉识别（适用存量清理）。没有技术上的"无人区"，差距在知识库规模与误判控制。
  3. 自研可行性已被本次实测验证。我用 500 行原型脚本对这台机器完成：319 个顶层条目归属判定，识别出 106 项残留候选（约 1.5GB）与 约 11.9GB 可回收缓存。MVP 单人 1~2 周可完成。
  4. 主要难点不是扫描，而是"判定"与"防误杀"。知识库长尾（名称≠产品名）、便携软件盲区、共享组件、DPAPI 等敏感目录，任何一个处理不好都会造成不可逆损失。
  5. 建议：P0 先用现成工具（BCUninstaller）清理存量；P1 若决定自研，定位"只读分析器 + 置信度报告"，删除永远交给人；P2 产品化需长期知识库运营，可参考 BCU 源码（Apache 2.0 可商用）。

三、技术方案剖析：三条成熟路线

路线原理精度适用时机成本与代表产品
A. 安装监控/快照 diff 安装前拍一次全系统快照（注册表+文件系统），装完再拍一次，diff 得到精确变更集；卸载时按集回滚 最高（有 ground truth） 只管未来：监控期间装的软件；对已存在软件无追溯力 IO 开销大、需常驻；Total Uninstall、Ashampoo、Revo Pro、HiBit
B. 卸载后残留扫描 跑完官方卸载器后，按程序名/厂商/安装路径启发式扫注册表、AppData、Program Files、计划任务 中高（名称匹配+安全漏报策略） 卸载动作发生时触发；对"历史上没管住"的存量无能为力 实现成本低；Revo、Geek、IObit、BCU
C. 事后孤儿识别
＝你的场景		 全盘扫 AppData/ProgramData → 与当前证据集交叉（注册表卸载项、商店包注册、运行进程、服务、自启动）→ 知识库匹配 → 哈希/GUID/陈旧度等启发式兜底 → 置信度分级输出 取决于知识库覆盖率（本次实测约 89%） 存量清理、接手二手电脑、定期体检 中等；BCU（Orphan 查找）、CleanMyPC Leftovers（停运）、社区脚本
结论：三条路线不是互斥而是互补——商用产品普遍 A+B+C 混合（如 Revo Pro）。自研时 C 是必做核心，B 可后置（接入卸载时机），A 是高成本增值项。

五、主要难点（按优先级分级，附本机实证）

P0 误杀防护——做错就是不可逆事故

风险点后果本机实证对策
DPAPI 密钥（Roaming\Microsoft\Protect、Crypto）删除 = 用户所有加密数据（浏览器保存的密码、证书、Wi-Fi 凭据）永久无法解密Roaming\Microsoft 真实存在（46.1MB，含 Protect/Crypto）永不将 Microsoft 系目录列为可删；删除操作必须走白名单
XP 兼容 Junction删除后旧程序路径解析故障Local 下实测存在 Application Data / History / Temporary Internet Files 三个 0 字节链接硬编码黑名单
UWP Packages 误删商店应用数据损坏、系统组件触发重装修复循环Local\Packages 1.3GB，下钻发现未注册目录（如 DesktopSpotlight）——可能是 staged 而非孤儿Packages 内部按包名精确比对，低置信默认保留
共享组件目录删一家殃及全家本机 Electron、CEF、AgoraAudio、VoipNNModel、WNS、Cache 等被多个应用共用归属引擎必须支持"多主归属"标记
删除动作本身误删无法挽回—只走回收站（IFileOperation + FOF_ALLOWUNDO）+ 还原点 + 永远人审确认

P1 判定准确率——核心竞争力所在

难点本机实证应对思路

六、结论性建议

总体结论

  1. 需求真实且已有成熟解：这是"卸载器"赛道的标准能力，不是未被开垦的需求；开源 BCU 已把事后孤儿识别做到可用且免费。
  2. 自研技术上完全可行：本次以约 500 行原型完成 89% 自动归属判定即为实证；MVP 门槛低。
  3. 护城河不在代码在数据：判定准确率 = 知识库覆盖率 × 防误判工程。中文软件生态（推广组件族、国产软件命名习惯）恰是国外工具的盲区，也是潜在差异化空间。
  4. 商业警示：CleanMyPC 停运说明纯 Windows 清理工具商业化艰难；BCU 找不到维护者说明开源维护同样有成本。个人自用/学习价值高，创业需谨慎。
