## 宿主限制声明（如实留档）

本宿主为**管理员会话**（T4-01 事故取证 `host_is_admin:true`）：真实 runas 静默通过、
不弹 UAC，且**禁止对真实提权实例做"异常退出"复现**（不能真杀提权进程/不可触发 UAC）。
按任务卡约定（验收②=注入式端到端），本留档以**替身句柄 + 替身退出码**驱动真实
UI 完整等待链：真启动 launcher UI + 替身发起返回（哨兵 33, 替身句柄）+ 替身等待
即时返回退出码 5（提权实例流水线失败码）——**零真实 runas、零 UAC、零真实
WaitForSingleObject**，等待链（等待→读退出码→tmp 日志→X-4 呈现）全部为产品真实代码。

## 方法（注入点均为产品代码文档标注的合法注入位）

1. 替身发起：模块属性替换 `launcher._shell_execute_runas`（launcher.py 防重生日志
   标注的全仓库唯一 ShellExecute 出口，H3 升级为 ShellExecuteExW）→ 返回
   `(ADMIN_RESCAN_LAUNCHED_CODE=33, 4711)`（替身句柄），真实 ctypes 调用永不触达；
2. 替身等待：替换 `launcher._wait_for_single_object`（即时返回 WAIT_OBJECT_0）与
   `launcher._get_exit_code_process`（返回 5）——T4-03 区块 docstring 标注的
   "测试零真实等待"注入位；
3. 落盘重定向：`disk_audit.TMP_DIR` 指向演示目录（`elevated._default_tmp_dir` /
   `launcher._default_host_tmp_dir` 文档标注的 monkeypatch 位）→ spec.json 与
   失败日志落演示目录，真实 `%LOCALAPPDATA%\DiskAudit\` 零触碰（E2E 后核对：
   真实 tmp 无 spec.json、无 done 标记）；
4. 真 UI 操作：真实 `mainloop()` 事件流（v1 驱动手动 `update()` 泵下 `_tkinter`
   拒绝跨线程 `after` 派发、呈现环节未走完——**驱动层问题，非产品问题**，v2 修正
   为 mainloop 事件流，与生产/G2 run_audit_async 先例一致）→ `tk.Tk()` 真实开窗
   → `build_scope_ui` 组装 → Radiobutton.invoke() 选择 P4 首位预设（%APPDATA%）
   → **以管理员身份重扫**按钮 invoke()（即真实 `_on_admin_rescan` 点击回调）；
5. 截图：pwsh System.Drawing.CopyFromScreen（X-4 文案落定后窗口保持期捕获，
   文件见同目录 `注入式异常退出-状态栏截图.png`，全屏 2560×1440 与 T4-02 同式）。
