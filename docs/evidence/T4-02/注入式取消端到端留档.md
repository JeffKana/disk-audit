# T4-02（H2）· 注入式取消端到端留档（验收②替代证据）

日期：2026-11-05 · 执行：T4-02 执行 Agent（AI 辅助） · 分支：feature/H2-UAC取消处理

## 宿主限制声明（如实留档）

本宿主为**管理员会话**（T4-01 事故取证 `host_is_admin:true`）：`ShellExecuteW runas`
静默通过、**根本不弹 UAC**，任务卡验收②的"UAC 弹窗点否"环节在宿主上**物理不可复现**。
按任务卡约定，真实 UAC 取消路径以 **R-M2 VM 复验覆盖**（VM 恢复 UAC 提示模式后测，
报 PM 认定）；本留档为**注入式替代**：真启动 launcher UI + 替身 ShellExecuteW 返回
`ERROR_CANCELLED(1223)`，对真实取消回调链做端到端断言，**零真实 runas、零 UAC 触发**。

## 方法（注入点均为产品文档标注的合法注入位）

1. 替身发起：模块属性替换 `launcher._shell_execute_runas`（launcher.py 防重生日志
   标注的全仓库唯一 ShellExecuteW 出口）→ 返回 `elevated.ERROR_CANCELLED(1223)`，
   真实 ctypes 调用永不触达；
2. 落盘重定向：`disk_audit.TMP_DIR` 指向演示目录（`elevated._default_tmp_dir`
   文档标注的 monkeypatch 位）→ spec.json 落演示目录，真实
   `%LOCALAPPDATA%\DiskAudit\` 零触碰（E2E 后核对：真实 tmp 无 spec.json）；
3. 真 UI 操作：`tk.Tk()` 真实开窗 → `build_scope_ui` 组装 → Radiobutton.invoke()
   选择 P4 首位预设（%APPDATA%）→ **以管理员身份重扫**按钮 invoke()（即真实
   `_on_admin_rescan` 点击回调）；
4. 截图：pwsh System.Drawing.CopyFromScreen（窗口保持期捕获，文件见同目录
   `注入式取消-状态栏截图.png`）。
