## 6. 归属率计算（9.2 口径，脚本与全文输出见同目录）

```
$ python 归属率计算脚本_9.2口径.py   → 归属率计算输出_9.2口径.txt（全文 116 行）

[L1-acc-22h2] %LOCALAPPDATA%: 119/124 = 95.97%（高12 中106 受保护1 低5）
              %APPDATA%:      6/6   = 100.00%
              双范围合计:     125/130 = 96.15%
[L1-acc-24h2] %LOCALAPPDATA%: 100/105 = 95.24%（高12 中87 受保护1 低5）
              %APPDATA%:      5/5   = 100.00%
              双范围合计:     105/110 = 95.45%
[L1-acc-22h2 高置信残留单元] 0 个
[L1-acc-24h2 高置信残留单元] 0 个
```

口径：分子 = confidence ∈ {受保护(=系统组件/硬保护), 高(=已安装/在用/可再生/高置信残留), 中(=中置信残留/Appx 在用)}
的候选数；分母 = 全部判定单元；低（归属未知）仅计分母（方案 9.2 原文）。"高置信残留"识别 = confidence=高 且
证据链含 5.1 高档措辞"高度可能为残留"（texts.py CONFIDENCE_WORDING）。
