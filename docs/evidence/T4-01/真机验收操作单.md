# T4-01 真机验收操作单（验收②：点击 → UAC → 提权重扫 → 管理员模式报告）

> **执行主体声明**：本操作单由 AI 执行侧（T4-01 执行 Agent）产出。**真实 UAC 触发由主会话
> 在负责人在场时按本单执行**，验收②终态以该次执行留档为准（截图/日志/进程核对存入
> `docs/evidence/T4-01/`）。AI 执行侧不得执行任何真实 `ShellExecuteW runas`——本卡的
> 端到端等效证据由注入式全链单测承担（tests/test_elevated.py::test_full_chain_stub_runas_to_admin_report_on_disk）。

## 0. 防重生纪律（最高优先级，上一次执行的事故先例）

- 2026-11-04 前次执行曾产生 **python 进程自重生链（34 个进程，每 2~3 秒互为父子）**。
  本卡实现已按四道结构性防线重构（自重启单点化 / 提权分支 AST 零自启动 / spec 一次性
  消费 / UI 仅单击无重试，AST 断言见 tests/test_elevated.py），但真机环节仍须遵守：
- **每步人工执行、无任何循环脚本**；"以管理员身份重扫"按钮**至多点击一次**，误点后等待
  本次流程自然结束，不得连续点击"补救"。
- 任一等待步骤超过 **2 分钟**即按 §5 异常处置核查进程表，不得继续等待。
- 全程监视 python.exe 进程计数（§2 基线 → §4 终态），**计数只许回落到基线，不许持续增长**。

## 1. 触发前置检查（IsUserAnAdmin 现状说明）

| # | 检查 | 命令 | 期望 |
| --- | --- | --- | --- |
| 1 | 系统 build ≥ 22621 | `pwsh -NoProfile -Command "[Environment]::OSVersion.Version.Build"` | ≥ 22621 |
| 2 | **执行会话非管理员** | `pwsh -NoProfile -Command "([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)"` | **False** |
| 3 | UAC 开启（EnableLUA） | `reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLUA` | 0x1 |

- **检查 2 是关键项**：若宿主（启动器）已以管理员运行，`ShellExecuteW runas` 将**静默
  放行、不再弹 UAC**，且每次发起不可见——上次中断事故的嫌疑环境即"宿主已管理员"
  （事故日志 `host_is_admin: true`，WIP 备份区 `_wip_backup_2/t401/docs/evidence/T4-01/e2e_run.log`）。
  务必在**普通权限**桌面会话执行本单。
- 须在**可交互的物理桌面或 VM 控制台**执行：UAC 弹窗出现在安全桌面，SSH/远程会话无法点按。
- 若检查 2 为 True：先关闭管理员终端，用普通权限终端重开，再复查。

## 2. 基线记录（发起前）

```
tasklist /FI "IMAGENAME eq python.exe" /FO CSV /NH
tasklist /FI "IMAGENAME eq conhost.exe" /FO CSV /NH
netstat -ano > %TEMP%\t401_netstat_before.txt
dir /B "%LOCALAPPDATA%\DiskAudit\reports"
```

记录：python.exe PID 集合（基线 B1）、conhost 计数、reports 目录既有文件清单（可选逐文件
certutil -hashfile MD5 留档，用于"既有报告零改动"断言）。

## 3. 单击触发步骤（每步一次，无循环）

1. 启动宿主（**普通权限终端**，工作目录 = 仓库根）：`python launcher.py`
   → 范围选择界面出现，底部状态栏为空。
2. 选择扫描范围：
   - 推荐 **C:\Windows\Prefetch**（自定义文件夹填入该路径）——正向对照：非管理员
     仅能看到根目录少量条目，提权实例可枚举数百个文件，报告正文出现
     `C:\Windows\Prefetch\...` 文件路径即为**提权确实生效**的正证据；
   - 或任一预设目录（%LOCALAPPDATA% 等）。
3. **单击"以管理员身份重扫"（一次）**。
4. UAC 弹窗出现 → 选择"**是**"。
5. 观察提权实例控制台窗口（黑窗，逐行日志），等待其打印完成行后自行关闭。

## 5. 验收③ netstat 抽查（人工两快照，无循环）

1. 点击发起、UAC 通过后，趁提权实例控制台窗口仍开着（O3 未完成前）：
   `netstat -ano > %TEMP%\t401_netstat_during.txt`
   同时记录当刻 python.exe PID 集合 P2（提权实例 = P2 − B1）。
2. 提权实例退出后：`netstat -ano > %TEMP%\t401_netstat_after.txt`
3. 人工核对：`t401_netstat_during.txt` 中**不含**任何以 P2 中 PID 结尾的行
   （netstat -ano 末列为 PID）。零命中 = 提权实例无网络连接（与代码审查结论、
   AST 断言 tests/test_elevated.py::test_elevated_module_zero_selfstart_and_zero_network
   互证）。三份快照更名后存入本目录。

## 6. 异常处置

| 现象 | 处置 |
| --- | --- |
| UAC 点"否" | 预期行为：无错误弹窗、无重试（E-5 本卡只留接口位；提示文案归 T4-02）。原报告不变，可直接重测。 |
| 控制台显示 `管理员重扫请求被拒绝（退出码 4）` | 一次性消费语义正常防御（请求已被消费或超时效）。等待 1 分钟后重新走 §3（重新点击会写入新请求）。 |
| 控制台显示 `管理员重扫失败：...` | 读 `tmp\admin_rescan_done.json` 的 `error` 字段定位；既有报告零改动（X-4 接口位，宿主提示归 T4-03）。 |
| **python.exe 计数持续增长 / 互为父子重生** | 立即终止验收：`taskkill /F /IM python.exe /T`（连带宿主），截图现场 + 记录 PID 父子链，回报主会话，不得继续任何点击。 |
| 任一步卡顿 > 2 分钟 | 按"重生链"预案核查进程表后再决定是否继续。 |
| 提权实例窗口一闪而过 | 按 O4/O5 检查 tmp 产物是否已产出；`admin_rescan_done.json` 的 `error` 字段留档。 |
