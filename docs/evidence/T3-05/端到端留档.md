## 验收④ UI 线程无阻塞证据

1. **自动化实证**：扫描进行中（非空闲状态）"中止体检"按钮可立即点击生效（上表步 3，
   点击后约 1~2s 内界面即切换不完整态）；扫描期间进度文本/路径持续刷新（步 2→2b）。
2. **架构断言**（`tests/test_launcher.py`，CI 常规执行）：
   - `test_run_audit_async_runs_scan_on_background_daemon_thread`：扫描在工作线程执行
     （线程 id ≠ UI 线程 id）且为 daemon 线程；
   - `test_run_audit_async_progress_forwarded_via_after_not_from_worker`：进度回调只经
     after 队列派发，工作线程内不直接执行任何 UI 更新，UI 更新全部发生在主线程侧。
3. **进程收尾**：整轮（中止+重扫+关窗）launcher 进程零异常输出（stdout/stderr 0 字节）、
   退出码 0；关窗后 UIA 寻窗 WINDOW NOT FOUND（无残留进程）。
