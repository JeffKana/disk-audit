# 交付与验收流程（磁盘体检 / disk-audit）

现行依据[DR-015](decisions/DR-015-2026-11-15-独测提PR与PM持续验收合入.md)和契约2.0.0；原MVP范围及里程碑口径以方案定稿为准。

流程：**PM任务卡 → 开发实现/自测/冻结SHA → 独测 → 测试侧提交PR及报告 → 当前head必需CI → PM验收 → 通过后直接合入 → 下一轮计划**。

## 0. 角色和权限

| 角色 | 责任与边界 |
| --- | --- |
| 负责人 | 确认原范围、资源和重大风险，发布终审；已持续授权本项目工作分支/PR与PM验收后合入，无需逐项请示 |
| PM主控 | 规划/分派、主状态和次数单写者；CI后裁决验收形式并最终验收，通过后合入及留证；自产出须先独立复核，已获负责人明确委托 |
| 执行实例 | 独立工作区开发、自测、冻结SHA/执行记录；接受独测/CI/PM具体退回，新SHA重测；不合入或改变标准 |
| 独测实例 | 未参与被测实现，另一工作区先设计后测试；失败直接回原执行者并同步PM，通过后推工作分支、提PR附完整脱敏报告；不修实现或判PM验收/合入 |

平台回执与业务状态分开，分派/代码/执行/独测/验收/合入制品各指定唯一写入实例；分支不是并发锁。独测、CI、PM同一轮产品退回只计一次，第二次立即升级负责人；纯平台启动失败单列，不计产品退回或重置原预算。

## 1. DoR与开发

任务卡明确待办ID/目标、版本化输入与方案依据、范围/约束、安全、依赖/可并行项、可执行标准、执行/独测/直接退回接收者/PM、授权来源与交接载体。单卡通常不超过两天，否则拆卡。

执行实例按S1/S2/S3先真实确认路径/两类版本和身份再写记录；冲突停报。读方案/开发规范/依赖代码；判定类逻辑测试先行含反例，落实类型、纯函数、零依赖、X-1异常与文案资源要求。跑适用pytest/selftest/import等，记录完成内容、决策依据、未尽项、自测和完整SHA；交冻结提交给指定独测。不得擅自改workflow、范围或安全底线。

## 2. 独测、直接退回和PR

独测先独立计划再执行，绑定完整SHA及执行记录版本。报告含环境、范围、命令/用途/时间/退出码、正反例、结果、缺陷、未覆盖项与证据hash；结果仅通过/失败/阻塞。

失败直接通知原指定执行者：失败SHA、复现、期望/实际、修复范围和新SHA重验要求，并同步PM登记状态/谱系。保留旧失败原件；不得自改实现、预期或标准换绿。修复和必要集成由执行侧完成，新head重测。范围/缺陷争议交PM，第二次产品退回升级负责人，不另开Task清零。

通过后由测试实例推送已测冻结head到工作分支，创建或更新同一PR，附脱敏完整报告到正文或其持有评论，保留原件和发布副本各自version/hash；不要只放外部不可达的本机路径。记录head的证据不提交进被测树；未脱敏raw、凭证、无关历史不默认上传。PR附任务标准/依赖栈/作者自测与独测结果来源，声明待PM最终验收。

## 3. CI与PM最终验收

当前PR head的必需检查通过后才作PM最终验收。CI红灯按真实缺陷、测试质量、环境差异、流程配置交责任实例；事件/本地环境故障交ops-runbook，保留失败证据，不跳测试或改变保护。head变化必须重测，base变化核受影响树和依赖。

PM按风险选择独立acceptance文件或版本化PR评审，保留七项：范围、规范、独测/回归、远端当前head必需CI、逐条标准、安全、结论。不得用本地绿、旧run或作者自测替代。报告/PR/CI head一致，引用报告与执行版本、授权和裁决时间。

- 通过：按持续授权直接合入，无需再问负责人。
- 有条件通过：最多三项明确责任/期限/关闭证据的非核心事项，不自动合入；条件关闭或裁决明确转为通过后再合入。
- 退回：具体要求交原执行侧，新SHA再独测；PM记录谱系，不覆盖测试失败。

合入前重核实际最新head、main基线、依赖栈、检查和保护，以expected-head约束正常PR合入；验收与merge-record分别由对应持有人写。核实际merge提交/树与main后续CI，更新PM主状态/待办/风险。PM自产出已获本次明确委托，但仍需独立实例先复核，不能省掉独立证据。

## 4. 下一轮、重大裁决与发布

PM按实际数据对照原M1–M5口径收数、排序和拆卡，独立且不写同一文件的任务可并行，热点串行；不猜完成率或降低阈值。实测/回归/环境事实交各持有人回填。D-执行由执行者范围内自决，接口歧义由PM技术裁决；范围、重大风险与资源仍负责人裁决。到期只触发检查，不推定可转派或扩权；保守默认仅用于事先授权且可逆、不改底线的事项。

MVP验收不等于发布。发布仍需原M5双包、干净机、安全与人工最终确认；不从持续合入授权推定外部程序/隐私上传、默认分支强推、保护绕过或新增Agent恢复预算。
