# references · 模板库

迁移新项目时按模板建文档，方括号为定制位。

---

## 模板一 · 任务卡（plan-cards 产出物）

```markdown
# Sprint <N>（W<N>）任务卡 · <起止日期>

按《交付与验收流程》§1 DoR 制作。分发建议：X/Y/Z 可并行；A 依赖 B；执行 Agent 每卡一分支一 PR；验收按 §3 SOP。

通用红线（所有执行卡适用）：不 merge、不 push main；不改验收标准；只写 <合规目录>；
新问题记"未尽事项"不顺手修；命令环境注意（指向 exec-sop/rules-map）；
<项目累积红线，如：测试禁真 KI、断言禁依赖 locale、显式传参>。

## T<N>-<NN> · <待办ID+名称>（待办 <ID>）
- **目标**：一句话
- **输入指针**：方案/规格节号 + DR 编号 + 归档/代码路径（精确到文件）
- **实现约束**：<历史教训写成硬约束；口径红线指到 DR>
- **验收标准**：①…②…③…（可执行命令或可测条件；数据类写明口径与基准）
- **依赖**：无 / <卡号>（并行或栈式）
- **执行记录**：（留空四项：做了什么 / 实现决策及依据 / 未尽事项 / 自测输出摘要）
```

## 模板二 · Sprint 验收报告（accept-verify 产出物，随波次追加、Sprint 末终章）

```markdown
# Sprint <N> 验收报告（项目经理 · 日期）

按《交付与验收流程》§3 验收 SOP 对 <N> 个交付分支逐卡执行。证据：<API/git/本地实证来源>。

## 1. 逐卡结论总表
| 卡 | PR | 分支 | CI | 范围 | 规范/测试 | 验收标准 | 结论 |

## 2. 退回单（如有）
现象（远端实证）→ 根因（PM 定位）→ 修复要求 → 重验口径 → 计数（x/2）

## 3. 条件项与裁决
现状 → 目标 → 方式；数据类裁决附选项与代价分析。

## 4. PM 独立抽查
（补执行记录缺的证据；本地复测数字与执行记录互证）

## 5. 合入顺序（尊重栈序）

## 6. 合入执行清单
（按分权标注执行人；平台故障应急路径留痕）

## 7. Sprint 评审数据
完成率 / 退回 / 缺陷与回归集增量 / CI 红灯分类 / 风险止损扫描 + 下阶段输入

## 8+. 后续波次与终章（追加）
里程碑闸门判定表：现状 → 目标 → 证据；判定后回填"实测"列。
```

## 模板三 · 决策记录 DR（ADR-lite）

```markdown
# DR-<序号> · <标题>

- 日期：<YYYY-MM-DD>
- 状态：已采纳 / 已被 DR-xxx 取代 / 已修订（<日期>，<节名>）

## 背景
<为什么现在要决策；约束与事实>

## 决策
<可执行的结论，分条；含明确否决的备选及否决理由>

## 理由
<数据/先例/原则；为什么不是其他选项>

## 影响面
<改哪些文件/流程；新增验收口径；回滚面；触发重开本 DR 的条件>
```

## 模板四 · 治理文档链骨架（project-bootstrap 产出物）

四份文档 + 一个目录，均带"变更记录"表（日期/变更/原因）：

```markdown
docs/governance/项目治理.md
  §1 仓库与目录（含二进制不进 git）   §2 分支与合入（PR-only + 保护三件 + 合入分权）
  §3 版本与发布（semver + 发布 checklist）  §4 变更管理（范围变更流程 + 不可协商底线）
  §5 决策记录（ADR-lite，decisions/）  §6 领域数据治理（如有知识库：来源铁律/字段纪律）
  §7 安全底线执行清单（逐条：底线/依据/检查方式）  §8 归档规范

docs/governance/开发规范.md
  语言风格与类型标注 / 核心逻辑纯函数化与依赖注入 / 零依赖白名单机制（增补走 DR）
  测试规范（覆盖要求/回归集回灌/数据驱动样例） / Git 与提交规范
  CI 门禁定义与失败处置 / AI 协作守则（产出必经人审+CI、权限边界、命令纪律）

docs/governance/环境基线.md
  §1 结论速览表（OS/工具链/内存/磁盘/已知限制，每行带影响）
  §2 关键环境操作步骤  §3 资源预算  §4 探测方法存档（可复现）
  变更记录表（环境事实变化必须回填）

docs/governance/decisions/DR-001-....md（模板三）

docs/agile/
  00_敏捷开发指南.md（角色/节奏/DoD/度量/回顾日志）
  01_产品待办列表.md（史诗/卡/追溯编号/状态列）
  0N_SprintN_计划与任务卡.md / 0N_SprintN_验收报告.md
```
