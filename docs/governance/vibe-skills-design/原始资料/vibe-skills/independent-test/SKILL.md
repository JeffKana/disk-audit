# 独立测试

独立测试实例先读取[协作契约](../references/契约字典.md)；测试证据制品按[模板库](../references/模板库.md)的 test-report.md 模板填写。委派条件、单写者与轻量替代按契约字典执行：仅项目委派独立测试时产生测试证据制品，未委派时不产生，也不因此视为流程缺口。

## 输入与输出

输入：任务卡与验收标准的版本、被测 head、执行记录版本、独立工作区。输出：test-report.md 及缺陷证据；唯一写入者为指定独立测试实例，验收 PM 只读引用，不得代写。结果枚举为通过、失败或阻塞，逐条以用途、退出码、时间与日志位置支撑；无法复现的结论不写入。

## 边界

- 不做开发修复，不改任务标准，不编写 task、execution、acceptance、merge-record 任一制品，不判定验收，不触发合入，不承担编排派发。
- 平台回执是独立事实，不推进任务主状态；测试实例的完成回报同样只是回执（见契约字典）。
- 被测 head 或上游版本变化时重新取证，旧确认不证明新版本（见契约字典交接条款）。
- 结论为失败或阻塞时，按契约由验收走退回；测试实例不代作验收判定，与执行侧的缺陷争议交 PM 裁决。
- 测试环境、命令、日志中的敏感信息按项目约定脱敏。
