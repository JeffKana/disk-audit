**最终结构与关键设计裁决**

| 组成 | 最终职责 |
| --- | --- |
| project-bootstrap | 立项治理基线，交规划输入 |
| plan-cards | 规划、制卡、指定实例与任务主状态 |
| exec-sop | 分派范围内实现、自测与独立执行记录 |
| independent-test | 项目委派时对已提交结果独立取证，产出独立测试报告 |
| accept-verify | 基于证据作验收三选一判定，合入权仍按项目授权 |
| ci-cd-ops | CI/CD 门禁设计与红灯诊断 |
| ops-runbook | 平台、传输与本地环境故障取证和恢复 |
| references/契约字典.md | 跨技能规则及制品写入者的唯一维护源 |
| 包根 CHANGELOG.md | 版本变更单一事实源，当前锚点 1.0.0 |
| references/模板库.md | 风险分级下的任务、交接、执行、测试与验收制品载体 |
| 离线只读检查器 | package／project 静态一致性检查，不接 CI、不写回、不提供运行时阻塞或调度 |
| evals/ 与 reports/ | 原版基线、E1–E10、待授权的 A/B/C 对照与接入验证／交付留痕 |

关键裁决保留如下：ci-cd-ops 与 ops-runbook 不合并，分别管理门禁与平台通道；independent-test 是独立证据环节，不代替 PM 判定；编排能力归平台，本包仅定义状态与证据契约；契约字典版本指共享规则版本，contract_version／task_contract 指任务范围与标准版本；project 模式仅适用于任务目录文件载体，PR 评论或 CI 制品等外部载体由人工核对；同名多来源按 exact ID 选择。

现有项目授权、安全底线和分权继续优先。Markdown 不提供锁或自动认领；第 2 次退回立即升级负责人；48h 保守默认仅限已获授权、可逆且不改变安全／验收底线的事项；go/no-go 口径预写死；轻量模式与风险强度分级保留。
