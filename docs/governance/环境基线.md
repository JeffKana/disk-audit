## 2. 虚拟化平台状态（2026-10-26 修订：VirtualBox 7.2.22）

> **修正记录**：2026-10-24 曾记录"Hyper-V 已开启（负责人确认）"。2026-10-25 实测：仅"虚拟机平台"（VMP/WSL2 底座）在运行，Hyper-V 管理栈（`vmms`/`Get-VM`/管理器）整个缺失——原记录与实际不符。完整启用 Hyper-V 需管理员 DISM + 整机重启；**负责人当裁决改用 VirtualBox**，免重启且不影响 WSL2/Docker。原 Hyper-V 存档步骤保留于文末参考。

**VirtualBox 7.2.22 现状（R-L1 建成，详见 05_Sprint2 卡 R-L1 执行记录）**：
- 安装：`D:\develop\software\VirtualBox-7.2.22-175245-Win.exe` 静默安装（winget 包 starkSV.msdl 同期安装，供微软官方 ISO 直链获取）。
- VM 清单（全部位于 `H:\Virtual Machine\`）：`L1-base-22h2`（22621.382 Pro zh-CN，快照 base-v1）、`L1-base-24h2`（26100.9711 Pro zh-CN，快照 base-v1）——两父镜像关机冻结；`L1-acc-22h2`、`L1-acc-24h2`（linked-clone 差分验收机，GT 已装）。
- 运行纪律：24H2 系 VM 禁止 GUI 附加（`--type separate` 会触发 GA 显示驱动挂死），全程 headless；主机自动睡眠（System Idle）会暂停 VM，长任务前置位 SetThreadExecutionState。
- Guest 访问通道：`VBoxManage guestcontrol run/copyto`（账号 qa）；已知坑：MSYS 路径转换会篡改 `/c` 等参数（置 `MSYS_NO_PATHCONV=1`）、copyto 源必须 Windows 路径、控制台打字避免 `>&|` 字符。

**已知影响与风险**：
- Docker Desktop / WSL2 不受影响（同用 HCS 底座，VirtualBox 以 WHP 模式共存）。
- 主机睡眠会暂停全部 VM；验收长任务期间建议外接电源并抑制睡眠。

**存档：Hyper-V 完整启用步骤（仅环境重建时参考，当前未启用）**：
1. 管理员 PowerShell：`DISM /Online /Enable-Feature /All /FeatureName:Microsoft-Hyper-V /NoRestart`
2. 重启后验证：`Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All`（State=Enabled）、`Get-VM`、`Get-Service vmms`（Running）。
3. 风险：CPU 进入 Hypervisor 模式；`bcdedit /set hypervisorlaunchtype off` 可临时关闭（会同时停用 WSL2/Docker）。
