## 2. Hyper-V 状态（已开启 · 2026-10-24 负责人确认）

> 历史记录：探测时点（2026-10-24 上午）功能尚未安装，负责人当日完成启用并确认，**无需重复检查或安装**。以下步骤仅作环境重建时的参考存档。

1. 以管理员身份运行 PowerShell，执行：
   ```powershell
   DISM /Online /Enable-Feature /All /FeatureName:Microsoft-Hyper-V /NoRestart
   ```
   （等价图形操作：`OptionalFeatures.exe` 勾选"Hyper-V"全部子项。）
2. 重启系统。
3. 重启后验证（管理员 PowerShell）：
   ```powershell
   Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All   # State 应为 Enabled
   Get-VM                                                                    # 应无报错返回空列表
   Get-Service vmms                                                         # 状态应为 Running
   ```
4. 验证通过后：更新本文档状态、勾销 Sprint 0 任务 0.7。

**已知影响与风险**：
- Docker Desktop / WSL2 不受影响（同用 HCS 底座）。
- 旧版 VMware Workstation（<15.5.5）与 Hyper-V 不兼容——本机未装，无此风险。
- 启用后 CPU 进入 Hypervisor 模式，游戏/反作弊个别场景性能略降；如遇问题可用 `bcdedit /set hypervisorlaunchtype off` 临时关闭（会同时停用 WSL2/Docker，验收期勿关）。
